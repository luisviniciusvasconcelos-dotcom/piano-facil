# Piano Fácil 🎹

App para aprender piano sem ler partitura: as notas caem até o teclado, com o nome escrito em cada uma, e o microfone do celular confere se você acertou.

**Abrir:** https://luisviniciusvasconcelos-dotcom.github.io/piano-facil/

- Modo Esperar, mãos separadas, velocidade ajustável, repetição de trecho, metrônomo
- Importa qualquer arquivo MIDI (.mid) de piano
- Funciona no celular; pode ser adicionado à tela inicial
